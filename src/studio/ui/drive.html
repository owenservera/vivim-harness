Live drive

Send one test prompt to a chat site through the capture browser and see whether the reply matched what was expected. This is a calibration check, not a full capture check. A dry run only plans the work. Nothing reaches a site until you execute it on purpose.

Before you run: the capture Chrome window must stay in the foreground — don’t minimise it or switch away while a job is running. Sites run one at a time; a campaign finishes one site before it starts the next.
