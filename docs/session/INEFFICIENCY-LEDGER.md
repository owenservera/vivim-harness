# Inefficiency and friction ledger

Tracks every slow, wasteful or brittle behaviour hit while using VIVIM through the owner's own AI webapp accounts. One row per finding. Status is one of `FIXED-UNVERIFIED` (code changed, not yet seen working live), `FIXED-LIVE` (seen working live), `OPEN`, `SUSPECTED` (not yet traced). Update the row in place; never delete one.

Source run: 2026-10-30, first live fan-out of the AI router and orchestrator across Z.ai, Qwen, DeepSeek, Claude and ChatGPT (`studio ask ... --pattern fanout`).
