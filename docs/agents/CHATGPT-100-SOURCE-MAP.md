**Source classification:** supported means a source path can perform the specified interaction; partial means it supplies a relevant primitive but lacks a concrete link to the full outcome; unsupported means the interaction control or reader is absent. A supported path can still fail at runtime. An adjacent key in a partial or unsupported row identifies an evidence or gap boundary, not an implementation of the missing capability. Each symbol key identifies a top-level declaration; factory symbols cover their nested methods. Source review does not imply provider access or test success.
