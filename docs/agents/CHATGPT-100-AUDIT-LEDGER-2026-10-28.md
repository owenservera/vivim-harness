## Remaining blockers and verification

The new `src/capture/conversation-rich.mjs` reader is observational only: 32 DOM parts per message at most, code/table/quote/list/math/link/image candidates; source query strings and URL fragments are stripped deliberately. It does not provide citation-source binding, artifact mutation, file uploads, Projects controls, or complete history traversal. The `read_conversation` control state comes from observed selectors, not backend completion.

Focused pure-source V8 assertions passed for module parsing, read-expression syntax, semantic propagation and text-budget exclusion. `test/unit/conversation-rich.test.mjs` (three tests) and `.github/workflows/chatgpt-source-audit.yml` were committed, but GitHub Actions runs show **failure with no retrievable job logs**; do not call the Node suite passed or failed at assertion level. No new live ChatGPT use case was run. The remaining U/P entries are actionable but unimplemented/unverified, not declared fixed.
